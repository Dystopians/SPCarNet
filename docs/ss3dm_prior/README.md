# SS3DM Prior Docs

This directory marks the documentation entrypoint for the SS3DM prior line.

Ownership rule:

- SS3DM-prior planning, experiments, update logs, and protocol docs belong to the SS3DM scope
- standalone `car model` docs belong in `docs/car_model/`
- shared repository location does not imply shared task ownership

Current note:

- many historical SS3DM documents still live at the top level of `docs/` with names such as `ss3dm_prior_*`
- future SS3DM-specific docs should be placed under this directory or explicitly linked from here
