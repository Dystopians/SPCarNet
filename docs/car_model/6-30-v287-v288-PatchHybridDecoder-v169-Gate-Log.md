## Code Changes

Primary file:

- `scripts/car_model/train_perceptual_surface_residual_decoder.py`

Implemented changes:

- Added `--image_loss_mode` with choices `global_proxy` and `patch_edge_v1`.
- `patch_edge_v1` adds support-local teacher proxy terms:
  - luma residual loss near active teacher-residual support;
  - local luma gradient-map matching;
  - patch high-pass residual matching;
  - residual-gradient matching against `teacher - parent`.
- Added configurable image proxy weights:
  - `--image_loss_patch_kernel`
  - `--image_loss_luma_weight`
  - `--image_loss_gradient_weight`
  - `--image_loss_highpass_weight`
  - `--image_loss_residual_gradient_weight`
- Added `--decoder_output_mode lowrank_plus_direct`.
  - It keeps the v282 low-rank baked surface texture basis.
  - It adds a bounded direct RGB residual head scaled by `--lowrank_direct_scale`.
  - Output is still generated by the same train/eval/target apply pipeline.

This is a real train/eval method change. It is not a render-only or reporting
change.

## Interpretation

v287 answers the patch-supervision question:

- The new patch/gradient-aware teacher proxy is a valid training objective and
  runs end-to-end.
- It does not improve the decisive flowers exact gate.
- Compared with v282b alpha 0.50, v287a is lower by `0.001912` PSNR and has
  worse LPIPS gain.

v288 answers the capacity question:

- Adding a bounded direct residual head is a real representation upgrade.
- It does not help target transfer. The best v288 exact is below v287a and
  below v282b alpha 0.50.
- Larger direct capacity hurts perceptual stability before it closes the PSNR
  gap.

The main bottleneck is now sharper:

- The low-rank baked texture carrier is not the only bottleneck.
- Adding direct RGB correction capacity does not solve target-view transfer.
- Patch/perceptual proxy losses improve the training story but still do not
  make the residual view-coherent enough on target views.
- Exact runs still lose SSIM/LPIPS against the parent while remaining roughly
  `0.456 dB` below Phase-J flowers PSNR.

## Next Recommendation

Do not run full9 from v287/v288.

The next useful method should attack target-view mismatch directly:

- train a source-view aggregation module that predicts residual only from
  target-compatible source views;
- include explicit source-view disagreement and OOD visibility features;
- evaluate a teacher projection upper bound that separates carrier capacity
  from target visibility mismatch;
- avoid more alpha scans, patch-loss weight scans, or direct-head scale scans
  unless a new diagnostic shows those are the limiting factor.
